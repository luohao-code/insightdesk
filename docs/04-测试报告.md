## 4 关键测试用例

### 4.1 批量任务并发一致性

- **步骤**：上传 3 张图片，并发数 2，创建批次，轮询至结束。
- **期望**：状态 succeeded，成功 3、失败 0，每项均有 document_id。
- **结果**：通过（修复并发计数缺陷后稳定）。
- **回归**：连续运行 10 次均通过。

### 4.2 失败重试与取消

- 已结束批次调用取消 → 400，提示"批次已经结束"；
- 无失败任务调用重试 → 400，提示"没有可重试的任务"；
- 非法图片创建批次 → 400，且不产生空批次。

### 4.3 SSRF 防护

| 输入 | 结果 |
| --- | --- |
| `http://127.0.0.1/` | 400，拒绝内网/本机 |
| `http://localhost/admin` | 400 |
| `http://192.168.1.10/` | 400 |
| `file:///etc/passwd` | 400，仅支持 http/https |
| 公网 URL 302 到 `http://10.0.0.5/` | 400，逐跳校验拦截 |
| `https://example.com`（公网 IP） | 允许，规范化后抓取 |

### 4.4 密钥安全

- 保存密钥后，`GET /api/settings` 返回 `••••••••`；
- 仅提交掩码时保持原值（幂等）；
- 数据目录与前端源码中检索不到明文密钥；
- CI 增加硬编码密钥扫描。

### 4.5 导出正确性

| 格式 | 验证点 | 结果 |
| --- | --- | --- |
| TXT | 非空、含元信息 | 通过 |
| CSV | UTF-8 BOM、表头、行数 | 通过 |
| JSON | 可解析、字段完整 | 通过 |
| DOCX | ZIP 头 `PK`、可被 Office 打开 | 通过 |

### 4.6 真实 OCR（RapidOCR）

- 输入：`docs/assets/sample-ocr.png`（1080×620，中英文混排）
- 引擎：`rapidocr`
- 耗时：约 6.3 秒（首次加载模型）
- 识别结果（节选）：

```text
识文台InsightDesk
OCR+AI智能文字工作台

支持中英文印刷体识别、批量任务与失败重试
```

结论：中英文印刷体识别可用，英文大小写存在个别误差（`OcR`），属 OCR 引擎正常波动。
