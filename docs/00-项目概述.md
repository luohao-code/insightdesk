# 项目概述

**项目名称**：识文台 InsightDesk —— OCR + AI 智能文字工作台
**课程**：课程综合实践 2：软件开发实践
**团队**：罗浩（负责人）、杨文杰、邹俊杰
**版本**：v1.0.0
**日期**：2026-11-11

---

## 1 一句话介绍

识文台是一套**基于 Web** 的文字工作台：上传图片或输入网页链接，系统完成中英文 OCR 识别，再通过大模型进行翻译、摘要、关键词与问答，最终形成可编辑、可检索、可导出的个人文字资产库；桌面版双击即用，并自动打开浏览器。

## 2 解决的问题

- 图片中的文字难以复用，人工录入效率低；
- 通用 OCR 工具缺少翻译、摘要、检索与结构化导出；
- 云端工具部署复杂、密钥管理混乱、隐私边界不清；
- 批量处理缺少进度、重试与失败定位。

## 3 主要成果

| 维度 | 成果 |
| --- | --- |
| 功能 | 图片/网页输入、四类 OCR、六类 AI 动作、批量队列、历史检索、七种导出、设置与看板 |
| 技术 | FastAPI + SQLAlchemy + SQLite FTS5；原生 ES Module 前端；SSE；PyInstaller |
| 规模 | 21,142 行代码（有效代码 17,619 行），119 个源码文件 |
| 质量 | 87 项自动化测试全部通过；真实 RapidOCR 验证通过；CI 门禁 |
| 安全 | SSRF 防护、密钥脱敏、路径校验、上传限制、CSV 注入防护 |
| 交付 | Web、Docker、Windows 桌面三种形态；需求/设计/测试/手册/三阶段报告齐全 |

## 4 系统边界

**包含**：OCR、AI 加工、批量任务、历史资产、导出、网页提取与自动打开、设置、统计、桌面启动器。

**不包含**：本地大模型训练、手写/公式/复杂表格、自动排版报告、视频理解、用户账号与支付、云同步。

```bash
python run.py
```
