# 部署与运维手册

**适用版本**：v1.0.0
**编写**：罗浩
**日期**：2026-11-09

---

## 1 部署形态

| 形态 | 适用场景 | 是否需要浏览器自动打开 |
| --- | --- | --- |
| 本地命令行 | 开发、演示 | 是（`run.py` 默认） |
| 服务器 / 局域网 | 团队共享 | 否 |
| Docker | NAS、云主机 | 否 |
| Windows 桌面 | 普通用户 | 是（启动器） |

## 2 环境准备

- Python 3.10+（推荐 3.12）
- 可写的数据目录（默认 `./data`）
- 如需本地 OCR：`pip install rapidocr-onnxruntime`
- 如需云端能力：准备百度/腾讯 OCR 与任一 OpenAI 兼容大模型的密钥

## 3 本地部署

```bash
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python run.py
```

生产环境建议不使用 `--reload`，并显式指定端口：

```bash
python run.py --host 0.0.0.0 --port 8770 --no-browser
```

> **并发说明**：SQLite 为单写者模型，建议只运行一个 uvicorn worker（内置线程池已负责任务并发）。多 worker 会争用写锁，反而降低稳定性。

## 4 局域网访问

1. 启动时绑定 `0.0.0.0`；
2. 在防火墙放行端口（Windows）：

```powershell
New-NetFirewallRule -DisplayName "InsightDesk 8770" -Direction Inbound -Protocol TCP -LocalPort 8770 -Action Allow
```

3. 其他设备访问 `http://<服务器IP>:8770`。

**安全提示**：应用未内置用户体系，局域网部署请通过网络 ACL、VPN 或反向代理 Basic Auth 限制访问。

## 5 Nginx 反向代理

SSE 需要关闭缓冲并延长超时：

```nginx
server {
    listen 80;
    server_name insightdesk.example.com;

    client_max_body_size 25m;

    location / {
        proxy_pass http://127.0.0.1:8770;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;

        # SSE
        proxy_buffering off;
        proxy_cache off;
        proxy_read_timeout 3600s;
    }
}
```

如需 Basic Auth：

```bash
htpasswd -c /etc/nginx/.htpasswd team
```

并在 `location /` 中加入 `auth_basic` 与 `auth_basic_user_file`。

## 6 Docker 部署

```bash
docker compose up -d --build
docker compose logs -f
```

- 数据卷：`./data:/app/data`
- 健康检查：每 30 秒请求 `/api/health`
- 升级：`git pull && docker compose up -d --build`

## 7 桌面版构建与分发

```powershell
pip install pyinstaller
powershell -ExecutionPolicy Bypass -File desktop/build_exe.ps1
```

产物：`release/InsightDesk.exe`。

- 单文件、无控制台窗口；
- 数据目录：`%APPDATA%\InsightDesk\data`；
- 启动失败：查看 `%APPDATA%\InsightDesk\data\logs\launcher_error.log`，或系统弹窗提示；
- 分发前建议在干净机器上验证一次，并评估杀毒软件误报。

## 8 数据备份与恢复

**备份**

```powershell
# 停止服务后
Copy-Item -Recurse data backup\data-20261109
```

**恢复**

```powershell
# 停止服务后
Remove-Item -Recurse data
Copy-Item -Recurse backup\data-20261109 data
```

**建议**：

- 重要数据每日备份；
- 备份前停止服务，避免 SQLite WAL 文件不一致；
- 如只备份数据库，请同时保留 `-wal` 与 `-shm` 文件，或先执行 `PRAGMA wal_checkpoint(TRUNCATE)`。

## 9 日志与监控

| 项目 | 位置/接口 |
| --- | --- |
| 应用日志 | `data/logs/app.log`（2MB × 3） |
| 健康检查 | `GET /api/health` |
| 系统信息 | `GET /api/system/info` |
| 最近日志 | `GET /api/system/logs?lines=200` |
| 存储占用 | `/api/system/info.storage` |

建议监控：

- 健康检查连续失败；
- 磁盘剩余空间；
- 批次失败率；
- 云端接口 429/5xx 比例。

## 10 升级流程

1. 备份 `data/`；
2. 拉取新代码；
3. 更新依赖：`pip install -r requirements.txt`；
4. 重启服务（数据库表结构由 `create_all` 自动补齐）；
5. 验证 `/api/health` 与首页；
6. 如涉及破坏性变更，按版本说明迁移数据。

## 11 安全加固清单

- [ ] 仅在内网或 VPN 内暴露服务；
- [ ] 反向代理启用 HTTPS 与访问认证；
- [ ] 不在前端或脚本中写死密钥；
- [ ] 定期检查 `/api/settings` 返回是否为掩码；
- [ ] 限制上传目录磁盘配额；
- [ ] 定期清理 `data/uploads` 与日志；
- [ ] 云端密钥使用最小权限与额度限制；
- [ ] 不将 `data/` 提交到 Git。

## 12 故障排查

| 现象 | 可能原因 | 处理 |
| --- | --- | --- |
| 页面打不开 | 服务未启动/端口占用 | 查看控制台地址与日志；更换端口 |
| 浏览器未自动打开 | 默认浏览器被拦截 | 手动访问控制台地址 |
| 所有引擎不可用 | RapidOCR 未安装、密钥为空 | 安装依赖或填写密钥 |
| 批量全部失败 | 密钥无效/额度不足 | 在设置中点击「测试」查看错误 |
| SSE 无进度 | 代理缓冲、防火墙 | Nginx 关闭 buffering；前端会降级轮询 |
| 网页提取 400 | 内网地址/动态页面/超时 | 换公开静态页；调整超时 |
| 导出乱码 | 使用非 UTF-8 打开 CSV | 用 Excel 直接打开（含 BOM） |
| exe 启动失败 | 缺少运行库/被杀软拦截 | 查看 launcher_error.log；添加白名单 |
| 数据库锁 | 多 worker/长事务 | 只运行一个 worker；重启服务 |

## 13 维护任务

- 每日：检查健康接口与磁盘；
- 每周：清理过期上传文件、查看失败批次；
- 每月：备份数据、更新依赖安全补丁；
- 每季度：轮换云端密钥。
