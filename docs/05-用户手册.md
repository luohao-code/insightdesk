# 用户手册

**适用版本**：识文台 InsightDesk v1.0.0
**更新日期**：2026-11-08

---

## 1 安装

### 1.1 方式一：源码运行（推荐开发者）

```powershell
cd insightdesk
py -3.12 -m venv .venv
.\.venv\Scripts\activate
pip install -r requirements.txt
pip install rapidocr-onnxruntime   # 可选：本地离线 OCR
python run.py
```

浏览器会自动打开 `http://127.0.0.1:8770`。若端口被占用，程序会自动选择下一个可用端口，并在控制台打印实际地址。

### 1.2 方式二：桌面版

1. 获取 `InsightDesk.exe`（自行构建或从发布页下载）；
2. 双击运行，等待浏览器自动打开；
3. 数据保存在 `%APPDATA%\InsightDesk\data`，卸载时可直接删除该目录。

### 1.3 方式三：Docker

```bash
docker compose up -d --build
```

访问 `http://127.0.0.1:8770`。

## 2 首次使用

首次启动使用**演示引擎**，无需任何密钥即可体验完整流程。演示引擎的识别文本是模拟数据，界面会显示黄色提示条。

如需真实识别，任选其一：

1. 安装 `rapidocr-onnxruntime`，在「设置 → OCR 引擎」选择 **RapidOCR（本地离线）**；
2. 申请百度智能云 OCR，填写 API Key / Secret Key；
3. 申请腾讯云 OCR，填写 SecretId / SecretKey 与地域。

AI 功能同理：可申请 DeepSeek、Kimi、智谱或通义的 API Key，填入「设置 → AI 大模型」。

## 3 页面说明

### 3.1 工作台

- 查看文字资产总数、今日新增、成功率、平均耗时；
- 近七日趋势、引擎使用分布、最近识别；
- 快捷入口：单图识别、批量处理、网页提取、AI 加工；
- 运行状态：数据库、可用引擎、运行时长、运行模式。

### 3.2 OCR 识别

1. 拖拽、点击或粘贴截图上传图片；
2. 点击缩略图选中要识别的图片；
3. 选择引擎、语言，必要时开启灰度化/增强对比度；
4. 点击「开始识别」；
5. 结果出现在右侧编辑器，可直接修改并自动保存；
6. 可复制、导出、删除，或使用下方 AI 快速处理（翻译/摘要/关键词/问答）。

> 提示：修改标题后按 Enter 或点击其他区域即可保存；`Ctrl+S` 可手动保存。

### 3.3 批量任务

1. 上传多张图片（最多 100 张）；
2. 填写批次名称、选择引擎/语言、设置并发数（建议 2–4）；
3. 点击「创建并开始识别」；
4. 在右侧查看实时进度、成功/失败数与每个任务的状态；
5. 失败任务可点击「重试失败项」；运行中的批次可取消。

### 3.4 AI 助手

- **文本处理**：选择动作（翻译/摘要/关键词/问答/润色/提纲），输入或从历史记录导入文本，设置选项后执行；
- **结果不会覆盖原文**，可复制、替换输入或导出原文；
- **文档问答**：选择一篇文档作为上下文，进行多轮提问；可查看历史会话。

### 3.5 历史记录

- 支持标题/正文/标签全文检索；
- 可按来源、引擎、收藏、标签筛选，支持多种排序；
- 单击「查看」或双击行打开详情，可编辑标题、正文、标签与收藏；
- 支持单条/批量导出与删除。

### 3.6 网页提取

1. 粘贴文章链接（http/https）；
2. 选择是否自动打开原文、是否保存记录、是否转为文字资产；
3. 点击「提取正文」；
4. 成功后展示标题、作者、站点、字数与正文，可复制、打开原文、转为文字资产或导出。

**自动打开说明**：

- 开关开启时，提取成功后自动打开原文；
- 桌面版调用系统默认浏览器；浏览器版在新标签页打开；
- 若弹出窗口被浏览器拦截，请允许本站弹窗。

### 3.7 设置

| 区域 | 可配置项 |
| --- | --- |
| 识别引擎 | OCR 引擎、百度/腾讯凭据、连接测试 |
| AI 模型 | 平台、API Key、Base URL、模型、温度、最大 Token |
| 任务与性能 | 并发、重试次数、退避倍数、超时、文件大小 |
| 网页提取 | 自动打开、抓取超时、响应体上限 |
| 外观与语言 | 深色/浅色/跟随系统、中英文 |
| 数据管理 | 文件保留天数、立即清理、资产统计 |

> 密钥输入框留空表示保持原值；保存后接口只返回掩码。

## 5 数据与隐私

| 数据 | 位置 | 说明 |
| --- | --- | --- |
| 数据库 | `data/insightdesk.db` | 文字资产、批次、设置 |
| 原图 | `data/uploads/` | 随机文件名 |
| 缩略图 | `data/thumbs/` | PNG |
| 日志 | `data/logs/app.log` | 滚动日志 |
| 导出文件 | 浏览器下载目录 | 由用户选择 |

- 所有数据默认保存在本机；
- 使用云端 OCR/AI 时，图片或文本会发送到对应服务商，请勿上传敏感资料；
- 密钥仅保存在服务端数据库，前端与打包产物不包含密钥；
- 网页抓取禁止访问内网地址。

## 6 常见问题

**Q1：识别结果是模拟文本？**
A：当前使用演示引擎。安装 RapidOCR 或配置云端密钥后切换引擎。

**Q2：引擎显示"不可用"？**
A：RapidOCR 未安装，或云端密钥未填写/未保存。可在设置中点击「测试」查看具体原因。

**Q3：批量任务部分失败？**
A：打开批次查看失败原因，常见为密钥无效、额度不足、图片损坏或网络超时。修复后点击「重试失败项」。

**Q4：网页提取失败？**
A：动态渲染或需登录的页面无法直接抓取；也可能触发 SSRF 防护（内网地址）。请使用公开的静态文章页。

**Q5：导出的 Word/Excel 打不开？**
A：请确认下载完整。CSV 已带 UTF-8 BOM，Excel 打开不应乱码。

**Q6：浏览器没有自动打开？**
A：检查是否被系统默认浏览器或安全软件拦截；手动访问控制台打印的地址即可。

**Q7：如何备份？**
A：停止服务后复制整个 `data/` 目录；恢复时覆盖回原位置即可。

**Q8：如何清理磁盘？**
A：设置 → 数据管理 → 立即清理；会删除超过保留天数的原图，文本记录保留。

## 7 卸载

1. 停止程序（关闭命令行窗口或桌面进程）；
2. 删除项目目录或 `InsightDesk.exe`；
3. 如需彻底清除数据，删除 `data/` 或 `%APPDATA%\InsightDesk\`。
