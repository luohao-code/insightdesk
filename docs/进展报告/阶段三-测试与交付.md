## 五、打包与部署验证

### 5.1 Windows 桌面版

- 构建命令：`powershell -ExecutionPolicy Bypass -File desktop/build_exe.ps1`
- 产物：`dist/InsightDesk.exe` / `release/InsightDesk.exe`
- 体积：**76.2 MB**（单文件）
- 实测：
  - 双击启动成功，自动打开浏览器；
  - 服务运行于动态端口（测试时 8771，因 8770 被开发服务占用）；
  - `/api/health` 返回 200，数据库状态 ok；
  - 数据写入 `%APPDATA%\InsightDesk\data`，日志正常滚动。

### 5.2 Web 与 Docker

- `python run.py` 启动正常，自动打开浏览器；
- Dockerfile 与 docker-compose 已提供，健康检查配置完成；
- Nginx SSE 配置已写入部署手册。
